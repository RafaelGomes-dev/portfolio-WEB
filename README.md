# Portfólio — Rafael Gomes

Portfólio pessoal em HTML, CSS e JavaScript puro, hospedado no GitHub Pages.

**Online:** [rafaelgomes-dev.github.io/portfolio-WEB](https://rafaelgomes-dev.github.io/portfolio-WEB/)

## Páginas

- **Home** — apresentação, projetos em destaque, skills, experiência e contato
- **Projetos** — todos os projetos com screenshots, stack e links (repositório / demo)
- **Sobre** — resumo profissional e linha do tempo
- **Contato** — canais de contato

## Estrutura

```
css/base.css       tokens, reset, navbar, botões, footer (compartilhado)
css/home.css       estilos da home
css/projects.css   estilos da página de projetos
css/about.css      estilos da página sobre
css/contact.css    estilos da página de contato
js/main.js         navbar, transição entre páginas, reveal no scroll
js/i18n.js         alternância PT/EN (PT vem do HTML, EN fica no dicionário)
js/carousel.js     carrossel de screenshots
```

## Recursos

- Alternância de idioma PT/EN com persistência em `localStorage`
- Layout responsivo (desktop, tablet e mobile)
- Acessibilidade: navegação por teclado, `aria-*`, `prefers-reduced-motion`
- Sem dependências além de Google Fonts, Font Awesome e Devicon via CDN
